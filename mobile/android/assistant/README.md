# Ayloo Assistant prototype

This is a separate Android application (`com.ayloo.assistant`). It does not replace or modify the Ayloo Keyboard app.

## Fast paths

- Select text in a compatible Android app, open the selection menu, tap **Ayloo**, then choose one action. Ayloo returns the replacement and also copies it.
- If an app does not expose text processing, share selected text to **Ayloo**. The result is copied for pasting.
- Open **Ayloo Assistant** for Dictate or Ask AI voice capture. Results are copied automatically.

The app requests only Internet and microphone access. It has no Accessibility service, overlay, account, history, screenshots, or sync.
